Bubble Sort Kya Hai?
==============================

Bubble Sort ek simple sorting algorithm hai jo adjacent (paas-paas) elements ko compare karta hai aur agar left element bada ho to unhe swap kar deta hai. Ye process tab tak chalta hai jab tak array sort na ho jaye.



Working->
====

Array = [5, 3, 8, 4, 2]

Pass 1
=========

5 3 → Swap → 3 5 8 4 2
5 8 → No Swap
8 4 → Swap → 3 5 4 8 2
8 2 → Swap → 3 5 4 2 8

Time Complexity ->
=======

Worst Case: O(n²)

Space Complexity->
=====
O(1)

for (int j = 0; j < arr.length - i - 1; j++)
=======
Conclusion=>
====
- i nahi likhoge → Output sahi aayega, lekin extra comparisons honge aur algorithm slow hoga.
- i likhoge → Sirf unsorted part compare hoga, isliye Bubble Sort zyada efficient ban jata hai.


Exam me 1 line ka answer:
==========

- i isliye use karte hain kyunki har pass ke baad sabse bada element apni correct position par pahunch jata hai. Isliye usse dobara compare karne ki zarurat nahi hoti, jisse unnecessary comparisons bach jate hain aur Bubble Sort fast ho jata hai.


Selection Sort
===============

Definition->

Selection Sort ek sorting algorithm hai jo har pass me unsorted array ka sabse chhota (minimum) element dhoondta hai aur usse current position se swap kar deta hai.



Working

Example:

5 3 8 4 2
Pass 1

Minimum = 2

Swap 5 aur 2

2 3 8 4 5
Pass 2

Minimum = 3

Already sahi position par hai.

2 3 8 4 5
Pass 3

Minimum = 4

Swap 8 aur 4

2 3 4 8 5
Pass 4

Minimum = 5

Swap 8 aur 5

2 3 4 5 8

Sorted Array ✅


Time Complexity ->
=======

Worst Case: O(n²)






Recursion
===============

Recursion ek aisi technique hai jisme ek function/method khud ko hi call karta hai, jab tak koi Base Case na aa jaye.


Recursion ka Structure
=================================

returnType functionName(parameters) {

    // Base Case
    if(condition) {
        return value;
    }

    // Recursive Call
    return functionName(smallerProblem);
}


Base Case Kya Hota Hai?
==============================

Base Case recursion ko rokta hai.

Agar Base Case nahi hoga to function infinite time call hota rahega aur StackOverflowError aa jayega.

Example:=>

if(n == 0) {
    return;
}

HashSet (Java) – Short Notes
===========
HashSet Kya Hai?
--------------
Java Collection Framework ka part hai.
Unique elements store karta hai.
Duplicate values allow ❌
Insertion order maintain nahi karta ❌
Sirf 1 null value allow karta hai ✅
Search, Insert, Delete ki average time complexity O(1)


Syntax
----------
HashSet<Integer> set = new HashSet<>();


Important Methods
----------------


set.add(10);        // Element add
set.remove(10);     // Element remove
set.contains(10);   // Check present hai ya nahi
set.size();         // Total elements
set.isEmpty();      // Empty check
set.clear();        // Sab delete

Iteration
--------------

Iteration ka matlab collection ke elements ko ek-ek karke access karna.

Iterato-->

Iterator<Integer> it = set.iterator();


hasNext()=>
===============

Check karta hai ki next element available hai ya nahi.
Return type: boolean
Agar next element hai → true
Nahi hai → false
while(it.hasNext()){


next()=>
===============
Current element ko return karta hai.
Iterator ko next element par move kar deta hai.
System.out.println(it.next());


Complete Example=>
=======================
Iterator<Integer> it = set.iterator();

while(it.hasNext()){
    System.out.println(it.next());
}
